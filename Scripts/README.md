# Scripts folder
Current available scripts.

Non-experimental ones are in this folder.

# How to run scripts
Running scripts are quite easy.

## Requirements:
Root, and an SCP client

### Tutorial:
1. Download the script to the printer (SCP client or any way to get it onto the printer, such as WinSCP or cURL if already installed)
2. Run `chmod +xwr (script.sh)`
3. Do `./(script.sh`

Now you've successfully ran the script. Have fun modding!
