# Creator 5 Research

This directory contains research and architecture material that supports Creator 5 mods. It is not a collection of installation instructions: claims are labelled by evidence level, unknowns remain explicit, and safety-critical work must be validated on physical hardware before it becomes a mod guide.

## Reports

- [Feasibility of an Open, Clean Firmware Stack](Open-Firmware-Migration/README.md) — investigation of a staged migration from the Flashforge control stack to a debuggable Linux, Klipper, Moonraker, and Mainsail architecture.
